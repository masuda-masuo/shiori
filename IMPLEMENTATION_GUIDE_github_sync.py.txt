## 2. _auth_args 関数（git 認証用）

```python
def _auth_args(provider: TokenProvider) -> list[str]:
    """git -c http.extraHeader の引数を生成。"""
    token = provider.get_token()
    if not token:
        return []
    b64 = base64.b64encode(f"x-access-token:{token}".encode()).decode()
    return ["-c", f"http.extraHeader=Authorization: Basic {b64}"]
```

## 3. _GitHubAuth クラス（API 認証用）

```python
class _GitHubAuth(httpx.Auth):
    """httpx の Auth フック。リクエスト単位でトークンを注入。"""
    
    def __init__(self, provider: TokenProvider):
        self._provider = provider
    
    def auth_flow(self, request):
        token = self._provider.get_token()
        if token:
            request.headers["Authorization"] = f"Bearer {token}"
        yield request
```
